# 优惠券秒杀新基线三轮对照结果

测试日期：2026-10-10

## 测试口径

- GitHub-hosted Ubuntu Runner，JMeter 5.6.3；
- 200 并发线程、10 秒升压、每组持续 60 秒；
- 每次请求使用不同的用户 token 与 IP，每轮准备 250,000 份凭证及库存，避免 CSV EOF 提前终止线程；
- 两组共同保留 Redis Lua 库存校验、重复下单判断、原子预扣和滑动窗口限流；
- 基线：Redis Lua 预扣成功后，由请求线程同步执行 MySQL 事务；
- 优化：同样的 Redis Lua 预扣成功后，写入 Outbox 并投递 RabbitMQ，接口入队后返回，消费者异步落库；
- 两组的主要实验变量是“同步 MySQL”与“RabbitMQ 异步落库”；
- 业务拒绝、HTTP 错误或连接错误任一不为 0，该轮即判无效。
