# 优惠券秒杀三轮对照结果

测试日期：2026-10-02

## 测试口径

- GitHub-hosted Ubuntu Runner，JMeter 5.6.3；
- 200 并发线程、10 秒升压、每组持续 60 秒；
- 每次请求使用不同的用户 token 与 IP，初始库存及用户数据均为 100,000；
- 两组均执行一人一单校验、API/用户/IP 滑动窗口限流与数据库唯一索引；
- 为避免限流器遮蔽下游差异，两组统一使用 `RATE_LIMIT_MULTIPLIER=10`，生产默认值仍为 `1`；
- 基线为同步 MySQL 下单；优化组测量 Redis Lua 原子预扣与 RabbitMQ 入队，采样后启动消费者并等待全部订单落库；
- 业务拒绝、HTTP 错误或连接错误任一不为 0，该轮即判无效。
